# OmniLet 万应 白皮书

## 多端轻应用容器平台

**版本**：1.0.1（勘误版）
**日期**：2026年10月
**品牌**：OmniLet（万应）

---

## 摘要

OmniLet（万应）是一套面向多端发布与运行的轻应用容器平台。它让开发者用统一技术栈编写一套代码，即可编译发布到微信、支付宝、飞书、快应用等外部小程序平台，同时通过自研容器 SDK 让自有 App 获得运行轻应用的能力，实现热更新、可嵌入、UI 可设计，并支持高性能图表、表格、动画、3D 及 SCADA HMI 等复杂可视化场景。

OmniLet 的核心价值是：**一次开发，多端发布；自有容器，动态更新；高性能渲染，工业级可视化。**

---

## 1. 行业背景与挑战

移动互联网进入存量时代，App 功能越来越复杂，业务迭代速度越来越快。企业面临以下核心矛盾：

- **发版周期长**：原生 App 每次更新需经过应用商店审核，无法快速响应市场活动、运营策略调整。
- **多端成本高**：微信、支付宝、飞书、快应用等平台各自独立，一套业务需要多套代码，维护成本极高。
- **动态化能力弱**：传统 H5 性能差，原生动态化方案（如 React Native）热更新受平台限制。
- **复杂可视化需求**：工业、金融、物联网等领域需要高性能图表、3D、SCADA HMI，但小程序平台能力受限。
- **可嵌入性差**：企业希望将业务模块以轻应用形式嵌入现有 App，但缺乏统一容器和管理体系。

OmniLet 正是为解决这些矛盾而设计。

---

## 2. OmniLet 平台概述

OmniLet 是一套 **"编译时多端 + 运行时容器"** 的轻应用平台。它由三大部分组成：

- **多端编译引擎**：将统一 DSL/TS 代码编译为微信、支付宝、飞书、快应用等平台的小程序代码包。
- **自研容器 SDK**：嵌入自有 App，提供轻应用运行环境，支持热更新、安全沙箱、原生能力桥接。
- **管理后台与设计器**：提供可视化搭建、发布审核、灰度回滚、监控分析等运营能力（设计器自 Phase 2 起交付，见 §8 路线图）。

**一句话定义**：

> OmniLet 让企业用一套代码覆盖所有小程序平台，并让自有 App 获得媲美 FinClip 的轻应用运行能力，同时支持工业级高性能可视化。

```text
└─────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│                   OmniLet 管理后台                        │
│  应用管理 / 版本发布 / 灰度 / 审核 / 监控 / 数据分析       │
└─────────────────────────────────────────────────────────┘
```

**工作流**：

1. 开发者用统一 DSL/TS 开发，或通过可视化设计器拖拽生成页面。
2. 多端编译引擎生成各平台代码包。
3. 上传至管理后台，审核发布。
4. 自有 App 中的容器 SDK 检查更新，差分下载离线包。
5. 校验签名，加载到沙箱运行。
6. 渲染页面，调用原生能力，埋点监控。

## 4. 核心能力

### 4.1 多端编译与发布

OmniLet 支持将一套代码编译到以下目标平台：

| 平台 | 支持程度 | 说明 |
|---|---|---|
| 微信小程序 | ✅ 完整支持 | 以微信为基准语法，兼容 WXML/WXSS/JS |
| 支付宝小程序 | ✅ 完整支持 | 自动转换支付、登录、自定义组件差异 |
| 飞书小程序 | ✅ 完整支持 | 自动替换飞书登录、支付、消息等接口 |
| 快应用 | ✅ 支持 | 处理语法差异，输出 `.rpk` 包 |
| 自有容器 | ✅ 原生支持 | 直接运行 OmniLet 轻应用，支持热更新 |
| H5 / Web | ✅ 支持 | 输出 Web 版本，用于浏览器或 WebView |

**编译能力**：

- 条件编译：通过 `#ifdef` 等指令处理平台差异。
- 平台 API 抹平：统一 API 封装，底层调用各平台原生接口。
- 组件多态：同一组件在不同平台渲染为不同实现。
- 代码分包与差分：减小包体积，支持增量更新。

### 4.2 自研容器与热更新

OmniLet 容器 SDK 是平台的核心差异化能力，对标 FinClip，但增加了多端编译与高性能渲染。

**核心特性**：

- **JS 引擎**：支持 QuickJS / V8 / Hermes，可配置。
- **渲染引擎**：支持 WebView 渲染、原生渲染、混合渲染、自绘渲染。
- **原生桥**：JS 与原生双向通信，支持异步批量调用。
- **安全沙箱**：权限控制、签名校验、存储隔离、网络白名单。
- **离线包管理**：下载、缓存、校验、版本切换、回滚。
- **嵌入能力**：iOS 的 UIView/VC，Android 的 View/Fragment，Web 的 iframe/WebComponent（注：WebComponent/iframe 是容器嵌入宿主网页的外壳选项；页面组件的绘制机制统一为标准 HTML 标签 + class 约定，见架构文档）。
- **生命周期**：启动、前后台、路由、多实例、销毁。

**热更新流程**：

1. 管理后台发布新版本离线包。
2. 容器 SDK 检查更新，差分下载。
3. 校验签名，解密解压。
4. 静默切换版本，下次启动生效。
5. 支持灰度发布、A/B 测试、强制更新、回滚。

### 4.3 高性能渲染引擎

OmniLet 自研容器内置高性能渲染引擎，突破微信/支付宝/飞书等平台的能力限制。

| 能力 | 外部平台（微信/支付宝/飞书） | OmniLet 自研容器 |
|---|---|---|
| 高性能图表 | 受限，大数据量卡顿 | 原生高性能，支持海量数据 |
| 表格 | 虚拟滚动可优化，但性能有限 | 原生渲染，流畅滚动 |
| 动画 | 无原生 rAF，帧率不稳 | 完整 GPU 加速，丝滑流畅 |
| 3D | WebGL 残缺，性能差 | 完整 WebGL / WebGPU，支持自定义 Shader |
| SCADA HMI | 基本不可行，需 WebView | 完全可行，支持工业级组态 |
| 多线程 | 不支持 Worker | 支持 Web Worker，渲染与逻辑分离 |
| WASM | 受限 | 完整支持 |

**技术亮点**：

- **完整 WebGL/WebGPU**：直接调用 GPU，支持 Three.js、PixiJS、Konva 等图形库。
- **多线程渲染**：利用 Worker 将渲染与逻辑分离，避免阻塞 UI。
- **原生渲染路径**：可选将 UI 组件映射为原生控件，获得最佳滚动和动画性能。
- **实时数据通道**：WebSocket + 差分更新，支持 SCADA HMI 高频率数据刷新。

### 4.4 可视化设计器

面向设计师和运营人员，提供拖拽式页面搭建。

- **拖拽搭建**：组件拖拽、配置、数据绑定、事件编排。
- **设计稿导入**：支持 Sketch / Figma 设计稿转代码。
- **主题配置**：全局样式、暗黑模式、响应式布局。
- **预览发布**：实时预览，一键发布。
- **代码互通**：可视化搭建与代码开发模式可互相转换。

### 4.5 安全沙箱与权限体系

- **沙箱运行**：轻应用在独立沙箱中运行，无法访问宿主敏感数据。
- **权限控制**：按应用、页面、API 粒度授权。
- **签名校验**：离线包签名，防止篡改。
- **存储隔离**：各轻应用存储空间独立。
- **网络白名单**：限制轻应用可访问的域名。
- **审计日志**：记录所有敏感操作。

### 4.6 管理后台与运营闭环

- **应用管理**：创建、配置、版本管理。
- **审核发布**：提交审核、人工/自动审核、发布。
- **灰度发布**：按用户、设备、地域灰度。
- **A/B 测试**：多版本并行，数据对比。
- **监控告警**：启动耗时、崩溃、白屏、更新成功率。
- **数据分析**：PV/UV、留存、转化、页面性能。
- **CDN 管理**：离线包分发、缓存策略。

## 8. 路线图

**第一阶段：MVP（0-6个月）**

- 统一 DSL 与编译引擎，支持微信、自有容器。
- 容器 SDK（iOS/Android），支持基础组件与 API。
- 管理后台基础功能：应用管理、发布、监控。

**第二阶段：多端扩展（6-12个月）**

- 支持支付宝、飞书、快应用。
- 可视化设计器 Beta。
- 高性能渲染引擎（WebGL 2.0）。
- 灰度发布、A/B 测试。

**第三阶段：生态与工业（12-24个月）**

- 组件市场、模板市场。
- SCADA HMI 工业套件。
- 多线程渲染、WebGPU。
- 开放平台，第三方开发者入驻。

## 9. 总结

OmniLet（万应）是一套面向多端发布与运行的轻应用容器平台。它解决了企业在多端开发、热更新、高性能可视化、可嵌入等方面的核心痛点。通过"编译时多端 + 运行时容器"的双核架构，OmniLet 既能让一套代码发布到微信、支付宝、飞书、快应用等外部平台，又能让自有 App 获得运行轻应用的能力，并支持高性能图表、表格、动画、3D 及 SCADA HMI 等复杂场景。

**OmniLet 的愿景是：让轻应用无处不在，让多端开发不再重复，让高性能可视化触手可及。**
